This is a repository for supplemental materials for the research article "Unpacking teacher collaboration: validation of measurement models using exploratory structural equation modeling" by Waldejer et al. (2026).
In the zip-folder you will find another README will further details, R-scripts, data and corresponding codebook.
To avoid issues with filepaths/working directories, please download the zip folder and avoid changing the file structure in the folders.

Note that R version 4.1.0 or later is required to run the scripts without having to make changes. 

Annotation of corrections in utc_codebook done 12.10.2026.
Correction was made to the description of the variable tt1_sex3. The variable was incorrectly coded in original codebook, values were reversed.
Correction was made to the description of the variables tt1_cc1 and tt1_cc5. These two removed variables from the "Contrived Collegiality" scale were incorrectly described as "theoretically" redundant. This was in the case of use as part of a multidimensional scale. For individual use as a scale for the measure of contrived collegiality we recommend that all 6 items, with preficc tt1_cc*" in the codebook, be used together as they all are theoretically important and have strong loadings and communality (h2). For clarity, the description of removed items was changed to "removed for scale brevity/ exchangeable items".
